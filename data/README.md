# Local Experiment Inputs

Inputs are intentionally not bundled. See [Data](../docs/DATA.md) for the exact
filenames, schemas, provenance and distribution constraints.

After obtaining permission to use the original project data locally, create
`raw/`, `metadata/` and optional `calibration/` here. The notebook creates
`processed/` during execution. Place the two floor-map images in the repository
root. These experiment inputs and generated outputs are ignored by Git.
